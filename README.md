# EduPath-AI
Predicción del rendimiento académico mediante Machine Learning y Streamlit.


Plataforma desarrollada para predecir el rendimiento académico de estudiantes mediante técnicas de Machine Learning.
Tecnologías
Python
Pandas
NumPy
Scikit-Learn
TensorFlow
Streamlit
Modelos implementados
Regresión Lineal
Random Forest
XGBoost
Red Neuronal
Mejor modelo
Regresión Lineal
MAE: 0.1553
RMSE: 0.1966
R²: 0.9532
Aplicación
La aplicación permite:
ingresar información del estudiante;
estimar el promedio académico esperado;
identificar el nivel de riesgo;
mostrar fortalezas;
señalar áreas de atención;
generar recomendaciones para apoyar la toma de decisiones.
